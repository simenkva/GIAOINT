# giao-integrals

`giao-integrals` is planned as a C++20/pybind11 library for Cartesian
atomic-orbital integrals over complex gauge-including atomic orbitals (GIAOs),
also called London atomic orbitals.

Milestone 1 is complete. The repository contains the mathematical
specification and an independent pure-Python overlap engine. The C++20 core and
NumPy API begin in Milestone 2.
